The doubling machine: y = 2x

An exponential function multiplies. Put x into the machine and it multiplies 2 by itself x times.

The machine

Input x?
→
f(x) = 2x
Press Play
→
Output y?

What came out

xWorky = 2x
The pattern: each time x goes up by 1, the output is multiplied by 2. A linear function adds the same amount each step; an exponential function multiplies by the same amount.
Why is 20 = 1? Going down one step divides by 2: 22 = 4, 21 = 2, so 20 = 2 ÷ 2 = 1.
