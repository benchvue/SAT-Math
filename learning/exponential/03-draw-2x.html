Three things every exponential graph y = 2x shows

  • y-intercept (0, 1) because 20 = 1.
  • Negative x gives fractions: 2−1 = 12, 2−2 = 14. Going left halves the value each step.
  • Asymptote y = 0: halving never reaches 0, so the curve gets closer and closer to the x-axis but never touches it.
